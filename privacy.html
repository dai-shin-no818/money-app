マネーアプリ プライバシーポリシー

マネーアプリは、管理者が自分の家計簿をつけるためだけに作った個人用のアプリです。一般の利用者向けには提供していません。

扱う情報

レシートや請求書の写真、音声入力の内容、そこから読み取った日付・店名・金額・品目などの支出の記録です。

情報の使い方と保存先

写真と音声は、内容を読み取るために Google の Gemini API に送ります。写真と読み取った記録は、管理者本人の Google ドライブと Google スプレッドシートに保存します。家計簿をつける以外の目的には使いません。

第三者への提供

上の読み取りのために Google のサービスを使うほかは、情報を第三者に提供・販売しません。

Google のユーザーデータ

このアプリが Google アカウントから得るデータの利用と転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

削除

記録と写真は、管理者が Google ドライブとスプレッドシートからいつでも削除できます。
